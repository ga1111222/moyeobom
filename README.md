# 모여봄 소스 코드

세 학교 프로그램 탐색, 부산 남구 대학 연합 행사, 익명 관심 수요와 사전 설문을 제공하는 Cloudflare Worker 앱입니다.

## 빌드

Node.js 24 이상을 권장합니다. 외부 패키지 설치는 필요하지 않습니다.

1. `.openai/hosting.example.json`을 `.openai/hosting.json`으로 복사합니다.
2. Sites에서 발급받은 `project_id`를 해당 파일에 설정합니다.
3. `node scripts/build.mjs`로 빌드합니다.

DB는 D1 바인딩 `DB`, 스키마는 `drizzle/`을 사용합니다. 배포 시 `PLANNER_EMAIL`을 서버 환경 변수로 설정해야 담당자 기능을 사용할 수 있습니다. 인증키·실제 수요/설문 응답 등 운영 데이터는 포함하지 않았습니다.

## 검사

`node tests/feed.test.mjs`, `node tests/demand.test.mjs`, `node tests/feed-throttle.test.mjs`

# 모여봄
공개 URL: https://moyeobom-campus.gayoungk1.chatgpt.site

Worker ESM 기반 서버 수집 및 브라우저 탐색 UI. 의존성 없음.
- 원본: 경성대학교 교내소식 MN091 (3페이지), 교외소식 MN092 (3페이지), 비교과 교육과정 MN197 (2페이지).
- `/api/activities`: 접속 시 원본 서버를 요청, 페이지별 캐시 60초. 화면이 보이면 1분마다 다시 요청. 닫힌 화면을 위한 별도 스케줄 작업은 사용하지 않음.
- 실패한 페이지는 마지막 캐시(최대 24시간) 또는 배포 시 수집본을 반환하며 stale/error와 확인 시각을 노출. 자료가 오래되었어도 최신으로 표시하지 않음.
- 원문 ID 중복 제거. 재안내 및 기간 연장 공지는 개별 유지. 분류는 제목 기반 규칙이며 직원 채용/행정 공지 제외. 모집상태와 마감일을 추정하지 않음.
- `node scripts/build.mjs`: dist/server/index.js 및 dist/.openai/hosting.json 생성.
- `node --test tests/feed.test.mjs`: 실제 CMS 표본, 분류, 실패/부분 실패, 경로 검증. 실제 CMS 표본은 tests/fixtures/에 보관.
- 브라우저 저장은 로컬 관심 활동용. 비밀 키와 로그인 불필요. 공개 접근 유지.

## 학교별 프로그램 연결
- 경성대: 교내소식 3페이지, 교외소식 3페이지, 비교과 교육과정 2페이지.
- 국립부경대: 공지사항 https://www.pknu.ac.kr/main/163 최근 3페이지 (pageIndex).
- 동명대: 행사/모집 sub07_01_05.do 3페이지, 일반공지 sub07_01_01.do 2페이지 (article.offset).
- API: /api/activities?school=ks|pknu|tongmyong. 요청한 학교 소스만 수집하고 각 자료에 school_id 기록. 오류 시 학교별 마지막 자료와 확인 시각을 노출.
- 화면 선택 전에는 요청하지 않으며, 학교 전환 시 이전 요청 취소 및 응답 순서 검증. 브라우저 캐시 역시 학교별 분리.
- 교내외 혼합 게시판은 명시적으로 판별되지 않는 경우 교내외로 표시. 모든 학교에서 동일한 검색, 필터, 저장, CSV, 수요/설문 기능 제공.

## 제공받은 부경아이 비교과 자료
- data/pknu-programs.json: 사용자 제공 텍스트 120개 항목 중 동일 항목 1개를 합친 119개 프로그램. 회차와 기간이 다른 항목은 별도 유지.
- 제공 자료는 실시간 확인으로 표시하지 않으며 모집·운영 기간 및 정원·신청 인원을 자료 기준으로 표시.
- 모든 제공 자료와 국립부경대 비교과 버튼은 https://pknuai.pknu.ac.kr/web/nonSbjt/program.do?mId=216&rstOk=1&order=3 을 사용.

새 배포 서버에 기존 demand_signals 10건 복원 완료. 임시 복원 경로와 임시 키는 제거함.

## 부산 남구 대학 연합 행사
학교 선택 화면의 세 학교 카드 아래 별도 항목을 추가했습니다. namgu-union 컬렉션은 학교 목록과 분리되어 있으며 행사를 data/union-events.json에서 관리합니다. 아직 제공받은 행사 자료는 없으므로 목록은 비어 있습니다. 공동 행사 제안 수요와 사전 설문은 별도 대상으로 저장·발행할 수 있습니다.

2026 부산 지산학 혁신대전 아이디어 공모전, 2026 대학생 교류 한마당, 2026 국유재산 활용 창업 오픈캠퍼스, 2026 B-Star 성과공유회, 2025 B-Star 창업 아카데미, 2025 B-Star 발대식 등 6건을 기록했습니다. 각 항목에 행사일, 참가 대상, 출처를 함께 보관합니다. 대학생 교류 한마당은 국제신문 개최 보도, 나머지는 대학·행사 공식 자료를 출처로 사용합니다. 지난 행사도 기본으로 보이도록 연합 행사에서 전체 기간을 선택하며, BIX 모집 마감일과 진행 기간은 구분합니다.
